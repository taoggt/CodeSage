## 修订：核心工作改写（同日）

- 用户反馈：初版核心工作是参数堆砌（"function calling + 7 个工具 + 四类停止条件"），面试官看不出 CodeSage 是干嘛的。
- 改写原则（已写入文档「写法原则」小节，后续复用）：① 每条先答"解决什么问题"再答"怎么做"；② 数字只做证据不做主语，放句尾；③ 每个技术名词后跟一句人话。
- 新结构：主链路（一条命令出报告）→ 确定性/LLM 分层分工 → 自研 ReAct 循环（边查边判）→ 三区记忆压缩 → Harness 评测闭环 →（可选）性能自优化。三个版本同步改写。
